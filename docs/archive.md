# 依頼ページの月ごとの整理

「りりへの依頼」は追記だけのページなので、使うほど長くなり、見回りのたびに全部を読む時間が延びます。
古い完了済みの依頼を、月ごとのアーカイブページへ移して短く保ちます。

このページは、りり・みき・まむ・local-tasks の4つが読んでいます。
進行中の依頼を移すと照合が壊れるので、**移してよいものを道具で確かめてから、人が手で移します**。道具は読むだけで、何も書き換えません。

## 1. 移してよい依頼を確かめる

りりのMacで、りりの場所から実行します（`.env` の Notion 接続で、依頼ページを読むだけです）。

```
python3 scripts/archive_plan.py --before 2026-11
```

`--before 2026-11` は「依頼IDの日付が 2026-11-01 より前」の意味です。次のすべてを満たす依頼だけが「移してよい」に出ます。

- Notion の状態が「完了」で、りりの記録も完了（done）
- りりの投稿で、未送信・送信中・保留のものがない
- りりの local-tasks とまむ連携の記録、みき・まむの連携記録のどれにも出てこない

それ以外は「残す」に理由つきで出ます。

## 2. 移す

1. りりのフォルダに `STOP` ファイルを置いて、見回りを止める
2. みき・まむで進行中の連携がないことを確かめる
3. Notion で「りりへの依頼」の下に「りりへの依頼（アーカイブ 2026-10）」のような子ページを作る
4. 手順1で「移してよい」と出た依頼のブロックだけを、Notion の「移動」で子ページへ移す（複製はしない）
5. もう一度 `archive_plan.py` を実行し、移した依頼がどちらの一覧にも出ない（ページから消えた）ことを確かめる
6. `STOP` を消して見回りを再開し、数回 `python3 patrol.py --status` で異常がないことを見る

移した依頼は、みき・まむの連携の状態表示で「Notion保存」を確かめられなくなります。完了済みのものだけを移すのはこのためです。
